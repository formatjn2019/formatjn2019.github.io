# format2019的博客



最初搭博客写博客还是17年，曾经CSDN不那么烂的时候也在上面写过几篇

后来选框架写脚本，做成了现在的样子。


这个博客写了自己一些东西的见解和笔记，用来分享及方便自己查阅，其中内容难免偏颇，如有遗漏或错误之处欢迎与我联系。
