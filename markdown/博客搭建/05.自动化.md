05.自动化

#### 

Github Page 本身依赖于github action 

不再需要人工干预



服务器端可采用定时任务平台或者crontab 定时任务调用shell脚本来实现自动化



我用的是 dagu 定时任务平台

项目地址 [dagu-org/dagu](https://github.com/dagu-org/dagu)

由于我的dagu采用docker部署，并未部署在物理机上。调用宿主机的docker采用了docker来调用，看起来比较
笨重
采用ssh连接宿主机调用shell或者宿主机直接部署会方便很多。

dag如下

```yaml
schedule:
  - "0 3 * * *"
steps:
  - name: 获取更新
    executor:
      type: docker
      config:
        image: formatjn2019/vuepress-nav-tool:latest
        pull: false
        host:
          binds:
            - 项目路径:/blog
        autoRemove: true
    command: bash createNav.sh / "host名称"
  
  - name: 重启容器
    depends:
      - 获取更新
    executor:
      type: docker
      config:
        image: docker:latest
        pull: false
        host:
          binds:
            - /var/run/docker.sock:/var/run/docker.sock
            - /mnt:/mnt
        autoRemove: true
    command: docker restart blog  # 容器名
   
```
