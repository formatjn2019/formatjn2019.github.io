#### 3. 填入博客内容

所有markdown文件都放在markdown目录下(github Page只支持/和/docs目录，所以markdown文件放/docs文件夹写脚本会麻烦)。

README.md文件会被vuepress解析为目录，可以随便写一些内容上去，不需要手动写目录。目录生成的工作由Python脚本完成。

在里面所建立的每一个文件夹会被解析成导航栏中的一个button，所以最好不要写太多。可嵌套。

比如joplin导出的markdown文件和_resource资源文件，可以直接将导出路径设为markdown目录

#### 4. 清理joplin重复markdown文件（可选）

若不是采用joplin导出，这个步骤便没有必要。

```shell
python update_markdown.py
```

例如joplin 下存在 笔记的笔记本，其下有笔记1的文件。

第一次导出 markdown文件夹下会存在`笔记/笔记1.md`文件

第二次导出 markdown文件夹下会存在`笔记/笔记1.md`文件和`笔记/笔记1-1.md`文件

而运行该脚本后，原`笔记/笔记1.md`文件会被删除 `笔记/笔记1-1.md`被重命名为`笔记/笔记1.md` 若导出多次以最新的为准

#### 5 项目部署

* 拉取项目

  ```shell
  git clone 项目地址
  ```

* 生成索引，导航页

  注 在项目路径下

  ```shell
  docker run --rm -v $(pwd):/blog tool:latest bash createNav.sh / "https://www.baidu.com"
  ```

* 运行vuepress

  这样就能直接输入ip或者域名进行访问了

  ```shell
  docker run -d \
  			--name blog \
  			--restart unless-stopped \
              -v $(pwd)/markdown:/blog/docs \
              -v $(pwd)/package.json:/blog/package.json \
              -p 80:8080 \
             	blog:latest
  ```

* 附注 编译

  运行完成后/docs下编译好的文件，可采用nginx等部署

  ```shell
  docker run --rm \
             -v $(pwd)/markdown:/blog/docs \
             -v $(pwd)/package.json:/blog/package.json \
             -v $(pwd)/docs:/blog/docs/.vuepress/dist \
             blog:latest npm run docs:build
  ```

#### 6. Github pages 配置

在项目下

`Setting -> Pages -> Build and deployment` 下

**Source** 设为 Develop from a branch

**Branch** 设为 gh-pages /docs
