2269.找到一个数字的K美丽值（简单）

[2269.找到一个数字的K美丽值（简单）](https://leetcode.cn/problems/find-the-k-beauty-of-a-number/)



解法：模拟

对对应位置取模即可，应该注意边界值10 1

```go
func divisorSubstrings(num int, k int) int {
	div, result := 1, 0
	for i := 0; i < k; i++ {
		div *= 10
	}
	for n := num; n*10 >= div; n /= 10 {
		d := n % div
		if d != 0 && num%d == 0 {
			result++
		}
	}
	return result
}
```
